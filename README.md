## Projet de fin d'études : Attijari Bank

**Conseiller clientèle augmenté par l'IA** · Digital Center, Attijari Bank · 2026

Plateforme bancaire conversationnelle reposant sur une architecture **RAG** (*Retrieval-Augmented Generation*) :

- un **chatbot multilingue** (français / derja / anglais) pour répondre aux clients ;
- un **assistant pour les conseillers** (prise de rendez-vous, préparation des échanges clients) ;
- des embeddings de type Sentence-Transformers (MiniLM) adaptés au domaine bancaire, indexés dans ChromaDB ;
- une sécurisation des accès par double authentification (2FA) et authentification basée sur le risque.

`RAG` `LangChain` `Sentence-Transformers` `ChromaDB` `Llama 3.3 (Groq)` `FastAPI` `MongoDB` `React`

<sub>Projet réalisé en entreprise : le code source n'est pas public.</sub>
